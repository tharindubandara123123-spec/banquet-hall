NEW MINIKIRULA HOTEL WEBSITE
=============================

Files:
- index.html: website content and page structure
- styles.css: responsive styling and layout
- script.js: mobile navigation and WhatsApp enquiry form
- assets/: the six photographs supplied for this website

HOW TO VIEW
1. Extract the ZIP file.
2. Open index.html in a modern web browser.

HOW TO PUBLISH
Upload the complete folder contents to your web hosting provider's public website directory
(for example, public_html). Keep the assets folder alongside index.html.
